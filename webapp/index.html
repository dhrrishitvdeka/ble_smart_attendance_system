BLE Smart Classroom Attendance System

BLE-assisted attendance verification. The teacher device is the trusted root and the final attendance authority. BLE detection alone is never treated as presence.

Verification chain: authentication → registered device → current session → BLE communication → proximity evidence → challenge-response → teacher finalizes → PRESENT. Unverified students remain NOT VERIFIED, never auto-absent.

Demo accounts — Admin A001 / admin123 · Teacher T001 / teach123 · Students S001–S006 / stud123. Serve over http://localhost (see start-webapp.bat) so Web Bluetooth is available.
